# Ajuda e suporte

Para dúvidas de instalação e uso:

1. Consulte as seções **Instalação**, **Perfis de acesso** e **Limitações conhecidas** no [README](README.md).
2. Procure nas [issues existentes do projeto original](https://github.com/douglaspiero/net-inventory-ia/issues) por uma pergunta ou problema semelhante.
3. Se encontrou um defeito reproduzível, abra uma issue no [repositório original](https://github.com/douglaspiero/net-inventory-ia/issues/new).
4. Para sugerir uma melhoria, descreva o caso de uso, o resultado esperado e consulte as orientações exibidas pelo GitHub ao criar a issue.

Este projeto é mantido de forma independente; não há prazo garantido de resposta. Não inclua chaves, senhas, arquivos `.env`, banco de dados ou identificadores reais da sua rede em pedidos de suporte. Para uma vulnerabilidade, siga somente o canal privado em [SECURITY.md](SECURITY.md).
